# Справочник погрузчиков

Веб-приложение для ведения справочника погрузчиков и учёта зафиксированных простоев и неисправностей.

## Стек технологий

- **Backend:** C#, .NET 10, ASP.NET Core Web API, Entity Framework Core
- **База данных:** PostgreSQL 16
- **Frontend:** HTML5, CSS3, JavaScript
- **Контейнеризация:** Docker, Docker Compose

## Основные возможности

- **Справочник погрузчиков:**
  - Поиск по номеру погрузчика без учёта регистра и сброс фильтра.
  - Добавление и редактирование записей прямо в таблице.
  - Валидация обязательных полей и грузоподъёмности (до 3 знаков после запятой).
  - Запрет удаления погрузчика при наличии зарегистрированных простоев.
  - Подтверждение удаления записи и отмены редактирования.
- **Простои по погрузчику:**
  - Отображение простоев выбранного погрузчика (сортировка от новых к старым).
  - Автоматический расчёт времени простоя в часах и минутах (для действующих инцидентов — до текущего времени).
  - Создание, редактирование и удаление инцидентов через модальное окно.
- **Профиль пользователя:**
  - Указание ФИО текущего пользователя с автоматической подстановкой при изменении записей.

## Запуск проекта

Запуск базы данных, бэкенда и фронтенда одной командой:

```powershell
docker compose up -d --build
```

После запуска приложение доступно по адресу: `http://localhost:8080`
*(Миграции базы данных и начальные тестовые данные применяются автоматически при старте.)*

Остановка проекта:

```powershell
docker compose down
```

## API Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/health` | Проверка работоспособности сервиса и БД |
| `GET` | `/api/forklifts?search=...` | Список погрузчиков и поиск по номеру |
| `GET` | `/api/forklifts/{id}` | Получение погрузчика по ID |
| `POST` | `/api/forklifts` | Добавление погрузчика |
| `PUT` | `/api/forklifts/{id}` | Обновление погрузчика |
| `DELETE` | `/api/forklifts/{id}` | Удаление погрузчика |
| `GET` | `/api/forklifts/{forkliftId}/downtimes` | Список простоев погрузчика |
| `POST` | `/api/forklifts/{forkliftId}/downtimes` | Регистрация нового простоя |
| `PUT` | `/api/downtimes/{id}` | Редактирование простоя |
| `DELETE` | `/api/downtimes/{id}` | Удаление простоя |
